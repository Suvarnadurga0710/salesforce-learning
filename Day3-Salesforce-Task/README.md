# 23PA1A12C9-Day3-Salesforce

##  Overview

This repository contains the Day 3 Salesforce assignment completed as part of the Salesforce training program. The assignment focuses on Salesforce automation using Validation Rules, Record-Triggered Flows, and Apex Triggers within a Placement Management System.

---

##  Contents

### Part 1 – Interview Warm-up

Covered the following Salesforce concepts:

* Validation Rules
* Flows
* Apex Triggers
* Flow vs Trigger
* Record-Triggered Flow
* Salesforce Order of Execution

---

### Part 2 – Placement Management System

Worked on the Placement Management System to understand how automation can improve the recruitment process using Salesforce declarative tools.

---

### Part 3 – Design Challenge

| Requirement                   | Solution              |
| ----------------------------- | --------------------- |
| Reject duplicate applications | Validation Rule       |
| Auto-fill Application Date    | Record-Triggered Flow |
| Send Email Notification       | Record-Triggered Flow |
| Reject low CGPA               | Validation Rule       |
| Create Offer Letter Record    | Record-Triggered Flow |

---

### Part 4 – Hands-on Assignment

Implemented Salesforce Flow components including:

* Start Element
* Assignment Element
* Send Email Action
* Successful Flow Execution

---

### Part 5 – Validation Rule Challenge

Implemented Validation Rules for:

* Student CGPA must meet the Job's minimum CGPA.
* Application Date cannot be after the Job Closing Date.
* Mandatory fields cannot be left blank.

Screenshots of the validation rules and successful execution are included in this repository.

---

### Part 6 – Trigger vs Flow Debate

Analyzed suitable automation tools for different business requirements:

* Automatic field updates
* Creating related records
* Sending email notifications
* Calling external REST APIs
* Complex calculations
* Processing bulk records

---

### Part 7 – Mini Project Enhancement

Enhanced the Placement Management System by implementing:

* Record-Triggered Flow for automatically setting the Application Date
* Validation Rules for maintaining data quality
* Automatic Email Notification after application submission
* Automatic Offer Letter record creation when Application Status becomes **Selected**

---

### Part 8 – Debugging Challenge

Discussed:

* Automation conflicts
* Recursive execution
* Governor limit issues
* Best practices for designing scalable Salesforce automation
